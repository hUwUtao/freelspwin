# LSP Plugins for Windows

This repository builds the official LSP Plugins source release on a Blacksmith 2-vCPU Windows runner with the MinGW-w64 toolchain.

The workflow downloads the source archive linked from the [official download page](https://lsp-plug.in/?page=download&section=source), builds the CLAP, LADSPA, LV2, VST2, and VST3 plugins with UI support, bundles `libwinpthread-1.dll` from MinGW, and publishes both the raw plugin tree and a 64-bit Inno Setup installer. The installer defaults to CLAP and VST3, with VST2, LV2, and LADSPA available as optional components. It places plugins in the standard Windows CLAP, VST2, VST3, and LV2 locations; LADSPA is installed under `Program Files\LSP Plugins\LADSPA` and may need a host-specific scan path. It omits HTML documentation, so PHP is not required.

Pushes to `main` and pull requests build version 1.2.35 with LLVM/Clang by default. Publishing a GitHub release runs the build for its tag version (with an optional leading `v`) and attaches the installer to that release. The job uses two parallel build tasks to match the runner's vCPU count. ccache is saved between runs for the same toolchain and source release. To build another source release or select GCC, run **Build LSP Plugins for Windows** from the Actions tab and choose the release version and toolchain. The plugin tree and installer are available under the run's **Artifacts** section.
